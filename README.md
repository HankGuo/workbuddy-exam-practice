# 讲师认证题库自测

基于「WorkBuddy 讲师认证考试 · 题库合并（两卷去重 93 题）」做的单文件模拟练习 Web 应用。

- 题型覆盖：单选 56 · 多选 18 · 判断 19（共 93 题），实锤答案、推荐答案、高频必背均已标注
- 四大模式：背题模式（翻面看解析）、真实答题（按真实考试结构抽题 / 计时 / 判分）、错题本（localStorage 持久化）、备考要点（价格数字锚点 + 临场清单）
- 设计：水墨纸感配色（暖纸白 + 墨色 + 朱砂红单重音），衬线标题，克制教学风，零 emoji，移动端 ≥ 16px、触摸目标 ≥ 44px
- 形态：单个自包含 `index.html`，无外部依赖、无网络请求，可直接在微信内置浏览器打开

## 使用

直接用浏览器打开 `index.html` 即可。如需在微信内打开或分享，把它托管到任意静态服务（GitHub Pages / Cloudflare Pages 等）后转发链接。

错题本数据保存在浏览器本地（localStorage），清缓存会丢失；不会上传到任何服务器。

## 数据来源

题库文本来自内部备考资料 `题库合并-两卷93题-给吴熳.md`。`build_questions.py` 将其解析为结构化数据并内联进 `index.html`，可重跑以更新题库。
